## 프로젝트

### [KeepIt](https://github.com/oojoyhh/KeepIt)

저장해 둔 링크를 내용으로 검색하는 서비스입니다. 기획과 백엔드 통합을 맡았습니다. 사용자가 한 주 동안 어떤 주제의 링크를 많이 저장했는지 보여주는 주간 리포트 API도 만들었습니다.

같은 질문 107개로 리랭킹 적용 전후의 검색 결과를 비교했습니다. 찾던 링크가 첫 번째로 나온 질문은 66개에서 88개로 늘었고, 상위 5개 안에 나온 질문은 96개에서 94개로 줄었습니다. 팀에서는 첫 번째 결과의 정확도를 우선해 리랭킹을 적용했습니다.

### [대타구함](https://github.com/oojoyhh/daetaguham) · [데모](https://oojoyhh.github.io/daetaguham/)

직원이 대타를 구하고 점장이 승인하면 근무표가 자동으로 바뀌는 서비스입니다. 서비스 기획과 DB·API 설계를 맡았고, 구현에는 AI 코딩 도구를 사용했습니다. 승인 후 근무표에 바뀐 담당자가 표시되는 것까지 테스트했습니다.

### SKALA 팀 프로젝트

- [StudySpot](https://github.com/oojoyhh/spot-agent)에서 스터디카페 입지 점수를 계산하는 코드를 작성했습니다. 비교할 상권을 추가해도 기존 상권의 점수가 달라지지 않도록 여섯 지표의 채점 기준을 고정했습니다.
- [KV cache 기술 평가](https://github.com/oojoyhh/skala-KV-cache)에서는 평가 결과를 PDF로 만드는 부분을 맡았습니다. 본문의 인용 번호를 따라가면 참고문헌에서 해당 논문이나 자료를 찾을 수 있습니다.
