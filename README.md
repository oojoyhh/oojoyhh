## 김효주

AI 서비스의 기획·백엔드 통합·실제 데이터 기반 검증을 경험했습니다.

### 프로젝트

**[KeepIt](https://github.com/oojoyhh/KeepIt)** · AI 링크 아카이빙 서비스  
서비스 기획·백엔드 통합·주간 리포트 API 담당. 약 200건의 실제 기록으로 AI 출력을 검증했습니다.

**[대타구함](https://github.com/oojoyhh/daetaguham)** · 교대 관리 서비스 · 개인 프로젝트  
기획부터 DB·API 설계, 백엔드 구현·배포까지 진행했습니다. [데모](https://oojoyhh.github.io/daetaguham/)

**[StudySpot](https://github.com/oojoyhh/spot-agent)** · 스터디카페 입지 추천  
6개 지표의 추천 점수 계산과 공통 데이터 모델을 설계했습니다.

**[KV-cache 기술 평가 Agent](https://github.com/oojoyhh/skala-KV-cache)** · 기술 평가 보고서 자동화  
근거 인용·참고문헌을 연결하는 PDF 보고서 생성 로직을 구현했습니다.

### 경험

**법무법인(유) 율촌 · 지식관리팀 인턴**  
매주 약 600건의 자료 대조를 자동화하고 절차를 문서화했습니다. 주 5일에 걸치던 확인을 2일 흐름으로 바꿨습니다.
